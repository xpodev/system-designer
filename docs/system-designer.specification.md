## Requirements {#requirements}

- [R:opacity] **error** `opacity`: Every mediated Connection is opaque: what uses and what offers do not know how they are connected. <!-- std -->
- [R:mediation_separate] **error** `mediation_separate`: Every Mediation joins two levels: its What's Language and its Medium's are not one, nor does either extend the other. <!-- std -->
- [R:medium_blind] **error** `medium_blind`: No Medium knows what it carries: the Component defining a Medium uses no Language mediated over it. <!-- std -->
- [R:mediators_minimal] **error** `mediators_minimal`: A mediator knows its two Languages, and only them: a Component realizing a Mediation uses nothing else. <!-- std -->
- [R:projection_acyclic] **error** `projection_acyclic`: No Language is projected, eventually, into itself. <!-- std -->
- [R:generic_level] **error** `generic_level`: All arguments of a generic instantiation belong to one Language. <!-- std -->
- [R:imports_acyclic] **warning** `imports_acyclic`: No Component depends, eventually, on itself: no two import from each other, wherever they are. <!-- std -->
- [R:deployments_complete] **error** `deployments_complete`: In every Deployment, every Interaction an Instance's Component imports is reached by a Connection. <!-- std -->
- [R:interactions_abstract] **warning** `interactions_abstract`: Every imported Interaction is abstract: no Component is reached through an implementation vocabulary. <!-- std -->
- [R:exports_interfaces] **warning** `exports_interfaces`: Only interfaces are exported: no Export makes reachable a Component that has children. <!-- std -->
- [R:core_is_pure] **error** `core_is_pure`: The language package imports and uses nothing, and its Languages are one chain, Kernel to Systems. <!-- script -->
- [R:vocabulary_only] **error** `vocabulary_only`: A vocabulary Component holds Languages and nothing that acts: no Interactions, Transformations, Mediums or Deployments. <!-- script -->
- [R:editing_knows_no_core] **error** `editing_knows_no_core`: Editing reaches nothing: it knows no concept of the core. <!-- script -->
- [R:readers_dont_edit] **error** `readers_dont_edit`: Nothing that reads a System — Views, Perspectives, Diagnoser, Exporter, Formats, Writer, Verifier — reaches anything that changes one. <!-- script -->
- [R:repository_knows_no_metadata] **error** `repository_knows_no_metadata`: The Repository and its implementations reach no metadata, nor any Metadata Provider. <!-- script -->
- [R:workspace_joins_storage] **error** `workspace_joins_storage`: Only the Workspace imports both the Repository and the Metadata Provider. <!-- script -->
- [R:clients_are_hows] **error** `clients_are_hows`: No Component imports a client, clients offer no Interactions, and no Connection goes to one. <!-- script -->
- [R:every_interface_implemented] **error** `every_interface_implemented`: Every seam offers Interactions and has an implementation; each implementation uses the Languages of its Interactions; and only the seams are implemented. <!-- script -->
- [R:editors_follow_layers] **error** `editors_follow_layers`: Each concept editor implements Edit Kind, and its Language extends the editor's below it and speaks its own Systemathic layer. <!-- script -->
